QuickMail v0.8.63 Release Notes

Released October 22, 2026 — downloads for this release

Changed

Updated mail and encryption libraries

QuickMail now uses MailKit and MimeKit 4.18.1, which bring the Bouncy Castle encryption library up to 2.7.0.

Contact addresses no longer in the debug log

With debug logging on, QuickMail no longer writes the email address of each contact you save to its log.

Shortcut keys are reported to screen readers

Menu items, toolbar buttons and context menu items now give screen readers their shortcut keys, so Reply’s Ctrl+R can be heard along with it. Until now most menus only showed the key on screen. Your screen reader’s settings decide whether the key is read out. (#849)

  • Keys you reassign in Settings → Keyboard Shortcuts now show in the menus, toolbar tooltips and command palette, and are the keys screen readers are given. Before, all of them kept showing the original key.
  • Toolbar buttons no longer read their name and shortcut twice.
  • A key you assign to a command that has none by default, such as Calendar at Bottom of Folder List, now shows on its menu item too, in the context menus and the Help menu as well as the main menus. (#854)
  • The message list’s context menu now shows the keys for Reply, Reply All, Forward and Delete, and the folder menu shows Delete for Delete Folder.

Fixed

  • First-letter navigation in Settings → Keyboard Shortcuts. Typing a letter in the list of commands now moves to the next command whose name starts with it, as in the folder list. Before, typing a letter did nothing. (#852)
  • Ctrl+, opens Settings. The File menu has long shown Ctrl+, for Settings, but the key did nothing. (#849)
